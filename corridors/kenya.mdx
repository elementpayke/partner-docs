# Kenya (KE / KES)

Kenya supports **M-PESA mobile money** and **bank** rails for OnRamp and OffRamp.

## Discovery

```bash
# OnRamp providers (momo + bank)
curl -sS "$BASE/partner/catalog?country=KE&order_type=OnRamp" \
  -H "X-API-Key: $API_KEY" | jq '.data.onramp.countries.KE'

# Field requirements
curl -sS "$BASE/partner/order-requirements?country=KE&currency=KES&order_type=OnRamp" \
  -H "X-API-Key: $API_KEY" | jq '.data'
```

## OnRamp (momo)

Customer pays KES via M-PESA → receives USDC/USDT on your `wallet_address`.

See [Quickstart](/quickstart) for a full curl.

## OffRamp (momo)

Customer sends **Polygon USDT** to the deposit wallet returned on **accept** (not in the quote body).

1. Quote with `order_type: OffRamp`, `crypto_amount`, `refund_address`
2. Accept → read `data.accepted.payment_instructions.crypto_deposit`
3. Customer sends exact amount before `expires_at`
4. Webhook `order.settled` when fiat is paid out to momo

<Warning>
OffRamp deposit address is **per order** from accept response. Do not reuse addresses across orders.
</Warning>

## Bank rail

Use `payment_method.type: bank` and `network_id` from:

```bash
curl -sS "$BASE/partner/banks?country=KE&currency=KES&order_type=OnRamp&payment_method_type=bank" \
  -H "X-API-Key: $API_KEY" | jq '.data.banks[] | {id, name}'
```

Bank `network_id` values are also in catalog under `payment_methods.bank.providers[]`. For momo, use catalog only — **`GET /partner/banks` returns 422 for `mobile_money`**.
