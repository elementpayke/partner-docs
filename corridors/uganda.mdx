# Uganda (UG / UGX)

Uganda supports **mobile money** (e.g. Airtel) for OnRamp and OffRamp.

## Discovery

```bash
curl -sS "$BASE/partner/catalog?country=UG&order_type=OnRamp" \
  -H "X-API-Key: $API_KEY" | jq '.data.african_markets[0].onramp.mobile_money.providers'
```
