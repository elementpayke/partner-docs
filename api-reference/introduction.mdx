# API reference

Interactive reference for the Element Pay Partner API. Use **Try it** with your sandbox `X-API-Key`  -  requests go to the sandbox base URL configured for this site.

Auth header: `X-API-Key`.

## Corridor discovery + orders

| Method | Path |
|--------|------|
| `GET` | `/partner/catalog` |
| `GET` | `/partner/corridors` |
| `GET` | `/partner/payment-methods` |
| `GET` | `/partner/order-requirements` |
| `GET` | `/partner/banks` |
| `GET` | `/partner/rates/indicative` |
| `POST` | `/partner/orders/quote` |
| `POST` | `/partner/orders/{quote_id}/accept` |
| `GET` | `/partner/orders/{order_id}` |

`GET /partner/rates/indicative` is corridor **fiat vs USD** only — not ledger convert pricing. For cross-currency ledger FX use [Currency conversions](/customers/conversions).

Guides: [Quickstart](/quickstart) · [Quote and accept](/orders/quote-and-accept).

## Currency conversions (banking)

Requires vault approved/active **and** `products.deposit_account.status=ready`. Cross-currency between two accounts on the **same** `pcus_*`.

| Method | Path | Notes |
|--------|------|-------|
| `POST` | `…/conversions/preview` | `to_account_id`, `amount` → `preview_token`, `rate`, `expires_at` |
| `POST` | `…/conversions` | Confirm + `idempotency_key` before `expires_at` |

Guide: [Currency conversions](/customers/conversions) · [Route cheat sheet](/customers/route-cheat-sheet).

## External bank payouts (banking)

Requires vault approved/active **and** `products.deposit_account.status=ready`. Integrator order:

| Method | Path | Notes |
|--------|------|-------|
| `GET` | `…/accounts` / `…/accounts/{account_id}` | Resolve fiat `account_id` + balance |
| `GET` | `…/payout-methods` | Schemes + `required_fields` / `require_one_of` (CAD Interac, NGN NIP, GHS EFT, SEPA, ACH, SWIFT, …) |
| `GET` | `…/payout-banks` | Local `bank_code` directory (NGN / GHS / CAD) |
| `POST` | `…/payouts/preview` | → `preview_token` |
| `POST` | `…/payouts` | Confirm + `idempotency_key` |
| `GET` | `…/payouts/{payout_id}` | Poll |

Not the same as corridor [`GET /partner/banks`](/partner/banks) (quote `network_id`).

Guide: [External bank payouts](/customers/payouts) · [Route cheat sheet](/customers/route-cheat-sheet).

## Try it

1. Open an endpoint under this tab.
2. Set `X-API-Key` to your sandbox key.
3. Banking money-movement order in guides: accounts → (optional) deposit-instructions → book-transfers / conversions / sends → for external payouts: **payout-methods** → **payout-banks** (local rails) → **payouts/preview**.
