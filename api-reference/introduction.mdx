# API reference

Interactive reference for the Element Pay Partner API — discovery, quotes, order acceptance, customer vault, and deposit accounts.

Public identity for new integrations is **`customer_id`** (`pcus_*`). See [Customers quickstart](/customers/quickstart).

## Ramps & discovery

| Method | Path |
|--------|------|
| `GET` | `/partner/catalog` |
| `GET` | `/partner/corridors` |
| `GET` | `/partner/payment-methods` |
| `GET` | `/partner/order-requirements` |
| `GET` | `/partner/banks` |
| `GET` | `/partner/rates/indicative` |
| `POST` | `/partner/orders/quote` |
| `POST` | `/partner/orders/{quote_id}/accept` |
| `GET` | `/partner/orders/{order_id}` |

## Legacy entities (existing integrations only)

Do **not** adopt `/partner/entities/*` for new builds. Money ops not yet facaded under `customer_id` (deposit-instructions, sends, book-transfers, cards) remain on these paths for **existing** integrations until customer-scoped facades ship.

Use **Try it** on any OpenAPI endpoint with your sandbox `X-API-Key`. Requests are sent to the sandbox base URL configured for this site.
