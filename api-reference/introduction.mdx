# API reference

Interactive reference for the Element Pay Partner API — discovery, quotes, order acceptance, and international deposit accounts.

## Ramps & discovery

| Method | Path |
|--------|------|
| `GET` | `/partner/catalog` |
| `GET` | `/partner/corridors` |
| `GET` | `/partner/payment-methods` |
| `GET` | `/partner/order-requirements` |
| `GET` | `/partner/banks` |
| `GET` | `/partner/rates/indicative` |
| `POST` | `/partner/orders/quote` |
| `POST` | `/partner/orders/{quote_id}/accept` |
| `GET` | `/partner/orders/{order_id}` |

## Deposit accounts (entities)

| Method | Path |
|--------|------|
| `POST` | `/partner/entities/individuals` |
| `POST` | `/partner/entities/businesses` |
| `GET` | `/partner/entities` |
| `GET` | `/partner/entities/requirements` |
| `GET` | `/partner/entities/{entity_id}` |
| `POST` | `/partner/entities/{entity_id}/documents` |
| `POST` | `/partner/entities/{entity_id}/identification` |
| `POST` | `/partner/entities/{entity_id}/business-profile` |
| `POST` | `/partner/entities/{entity_id}/submit` |
| `POST` `GET` | `/partner/entities/{entity_id}/accounts` |

| `GET` | `/partner/entities/{entity_id}/accounts/{account_id}/deposit-instructions` |

| `POST` | `/partner/entities/{entity_id}/accounts/{account_id}/book-transfers` |
| `POST` | `/partner/entities/{entity_id}/accounts/{account_id}/sends/preview` |
| `POST` | `/partner/entities/{entity_id}/accounts/{account_id}/sends` |
| `GET` | `/partner/entities/{entity_id}/accounts/{account_id}/sends/{send_id}` |
| `POST` | `/partner/entities/{entity_id}/accounts/{account_id}/card-charges` |

| `GET` | `/partner/entities/{entity_id}/accounts/{account_id}/cards` |

| `POST` | `/partner/entities/{entity_id}/accounts/{account_id}/cards/{card_id}/unfreeze` |

<Note>
The **`/partner/entities/*`** surface (international deposit accounts / entity KYC, deposit instructions, book-transfers, stablecoin sends, card funding, and card issuing) is exported into this site’s `openapi.json` under the `partner-entities` tag, so every endpoint above has its own Try-it page. For end-to-end walkthroughs, see [International deposit accounts](/deposit-accounts/overview), [Card funding](/deposit-accounts/card-funding), and [Card issuing](/deposit-accounts/card-issuing).
</Note>

## Try it

Use **Try it** on any endpoint with your sandbox `X-API-Key`. Requests are sent to the sandbox base URL configured for this site.
