# API reference

Interactive reference for the Element Pay Partner API. Use **Try it** with your sandbox `X-API-Key` — requests go to the sandbox base URL configured for this site.

Auth header: `X-API-Key`.

## Banking (optional product)

Requires vault approved/active **and** `products.deposit_account.status=ready`. Prefer this call order when integrating payouts:

| Method | Path | Notes |
|--------|------|-------|
| `GET`/`POST` | `/partner/customers/{customer_id}/accounts` | List / open rails |
| `GET` | `/partner/customers/{customer_id}/accounts/{account_id}` | Balance + status |
| `GET` | `…/deposit-instructions` | Fund fiat / stablecoin |
| `GET` | `…/payout-methods` | Schemes + required fields |
| `GET` | `…/payout-banks` | Local `bank_code` directory |
| `POST` | `…/payouts/preview` | Quote-like preview → `preview_token` |
| `POST` | `…/payouts` | Confirm |
| `GET` | `…/payouts/{payout_id}` | Poll |
| `POST`/`GET` | `…/sends…` | Stablecoin sends |
| `POST` | `…/book-transfers…` | Internal fiat book |
| `POST`/`GET` | `…/cards…` / `…/card-charges…` | Issuing / acquiring |

Guides: [Accounts](/customers/accounts) · [Deposit instructions](/customers/deposit-instructions) · [Payouts](/customers/payouts) · [Route cheat sheet](/customers/route-cheat-sheet).

## Try it

1. Open an endpoint under this tab.
2. Set `X-API-Key` to your sandbox key.
3. Prefill path params (`customer_id`, `account_id`) from your vault.
4. For payouts: call **payout-methods** → **payout-banks** (local rails) → **payouts/preview** before confirm.
