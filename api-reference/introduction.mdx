# API reference

Interactive reference for the Element Pay Partner API — discovery, quotes, order acceptance, customer vault KYC, deposit accounts, and stablecoin sends.

Public customer identity is **`customer_id`** (`pcus_*`). See [Customers quickstart](/customers/quickstart) and [Accounts and banking](/customers/accounts-and-banking).

## Included endpoints

| Method | Path |
|--------|------|
| `GET` | `/partner/catalog` |
| `GET` | `/partner/corridors` |
| `GET` | `/partner/payment-methods` |
| `GET` | `/partner/order-requirements` |
| `GET` | `/partner/banks` |
| `GET` | `/partner/rates/indicative` |
| `POST` | `/partner/orders/quote` |
| `POST` | `/partner/orders/{quote_id}/accept` |
| `GET` | `/partner/orders/{order_id}` |

## Customers (vault KYC + accounts + banking)

OpenAPI tag: **`partner-customers`**.

| Method | Path |
|--------|------|
| `GET` | `/partner/customers/requirements` |
| `POST` | `/partner/customers` |
| `GET` | `/partner/customers` |
| `GET` | `/partner/customers/{customer_id}` |
| `PATCH` | `/partner/customers/{customer_id}` |
| `POST` | `/partner/customers/{customer_id}/documents` |
| `POST` | `/partner/customers/{customer_id}/submit` |
| `POST` | `/partner/customers/{customer_id}/deposit-account/retry` |
| `POST` | `/partner/customers/{customer_id}/accounts` |
| `GET` | `/partner/customers/{customer_id}/accounts` |
| `GET` | `/partner/customers/{customer_id}/accounts/{account_id}` |
| `GET` | `/partner/customers/{customer_id}/accounts/{account_id}/deposit-instructions` |
| `POST` | `/partner/customers/{customer_id}/accounts/{account_id}/sends/preview` |
| `POST` | `/partner/customers/{customer_id}/accounts/{account_id}/sends` |
| `GET` | `/partner/customers/{customer_id}/accounts/{account_id}/sends/{send_id}` |

Guides: [Customers quickstart](/customers/quickstart) · [Accounts and banking](/customers/accounts-and-banking) · [Route cheat sheet](/customers/route-cheat-sheet).

<Note>
Legacy entity account routes under `/partner/entities/{entity_id}/accounts/...` remain for older integrations. New work should use `pcus_*` customer paths only.
</Note>

## Try it

Use **Try it** on any OpenAPI endpoint with your sandbox `X-API-Key`. Requests are sent to the sandbox base URL configured for this site.
