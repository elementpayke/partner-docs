# Book-transfers (fiat)

Move funds **between two fiat accounts under your API key** with **preview then confirm**. Both accounts must be `active` and the **same currency**. Fee observed for same-currency book-transfer: often **0**. See [Accounts & deposits](/deposit-accounts/accounts) first.

<Warning>
**Incremental facade:** Customer-scoped book-transfers under `/partner/customers/{customer_id}/…` are **coming**. Paths below are **legacy `/partner/entities/…`** for **existing** integrations only. **New integrators:** complete vault KYC + customer accounts now ([Customers quickstart](/customers/quickstart)); do not build new entity KYC or treat entity URLs as the long-term API.
</Warning>

<Warning>
**Fiat only.** There is **no** stablecoin book-transfer and **no** inter-customer crypto book-transfer product. To move USDC/USDT off-platform, use [Stablecoin sends](/deposit-accounts/sends). To change currency, use [Currency conversion](/deposit-accounts/currency-conversion).
</Warning>

<Note>
All calls use `X-API-Key` and `$BASE` = sandbox or production. `$ACCOUNT_ID` is the **source** fiat account. `$ENTITY_ID` below is legacy only.
</Note>

## Preview

```bash
curl -sS -X POST "$BASE/partner/entities/$ENTITY_ID/accounts/$ACCOUNT_ID/book-transfers/preview" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to_account_id": 21,
    "amount": "25.00"
  }' | jq '.data'
```

```json
{
  "preview_token": "<token>",
  "currency": "EUR",
  "from_account_id": 17,
  "to_account_id": 21,
  "amount": "25.00",
  "fee": "0.00",
  "receive_amount": "25.00",
  "fee_status": "estimated",
  "expires_at": "2026-07-29T16:35:00+00:00"
}
```

## Confirm (with idempotency)

```bash
curl -sS -X POST "$BASE/partner/entities/$ENTITY_ID/accounts/$ACCOUNT_ID/book-transfers" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "preview_token": "<token>",
    "idempotency_key": "partner-move-001"
  }' | jq '.data'
```

```json
{
  "id": "<transfer_id>",
  "status": "completed",
  "from_account_id": 17,
  "to_account_id": 21,
  "currency": "EUR",
  "amount": "25.00",
  "fee": "0.00",
  "receive_amount": "25.00",
  "fee_status": "final",
  "created_at": "2026-07-29T16:35:10+00:00"
}
```

Re-confirming with the **same `idempotency_key`** returns the **same transfer id** (no double debit). Statuses: `pending` \| `completed` \| `failed`.

## Fees

There is no separate fee-estimate API. Prefer **confirm** `fee` / `fee_status: "final"` for user-facing cost when present. Same-currency fiat book-transfer fee is typically `0.00`.
