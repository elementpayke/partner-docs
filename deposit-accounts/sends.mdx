# Stablecoin sends

Send USDC from a stablecoin account to an external or in-network wallet. Same **preview then confirm** shape as [book-transfers](/deposit-accounts/book-transfers), using `to_address` instead of `to_account_id`.

<Warning>
**Sandbox limitation:** confirm/settlement can hit a transient upstream error in sandbox even when preview succeeds. **Production** sends work on a funded USDC account. Treat `account.send.completed` / `account.send.failed` (or GET send) as the source of truth—do not rely on sandbox alone for send QA.
</Warning>

{/* INTERNAL TODO: when sandbox send confirm is reliable, soften/remove the sandbox limitation Warning above. */}

- **Minimum:** `1.00` USDC. Smaller amounts fail fast at preview with `422 { field: "amount", minimum: "1.00" }`.
- **Network** must match the account (`Base` \| `Polygon`).
- **Endpoints:** `POST .../sends/preview`, `POST .../sends`, `GET .../sends/{send_id}`.
- **Send statuses:** `processing` → `submitted` → `completed` \| `failed`.

<Note>
All calls use `X-API-Key` and `$BASE` = `https://sandbox.elementpay.net/api/v1` (or production). `$ACCOUNT_ID` is the source **stablecoin** account, funded first (see [Fund an account](/deposit-accounts/accounts#fund-an-account)).
</Note>

## Preview

```bash
curl -sS -X POST "$BASE/partner/entities/$ENTITY_ID/accounts/$ACCOUNT_ID/sends/preview" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to_address": "0xRecipientWalletAddress",
    "amount": "5.00",
    "network": "Base"
  }' | jq '.data'
```

```json
{
  "preview_token": "<token>",
  "currency": "USDC",
  "network": "Base",
  "amount": "5.00",
  "fee": "0.00",
  "receive_amount": "5.00",
  "fee_status": "estimated",
  "chain_disclaimer": "Send only USDC on Base. Funds sent on the wrong network may be lost.",
  "expires_at": "2026-07-29T16:40:00+00:00"
}
```

## Confirm

```bash
curl -sS -X POST "$BASE/partner/entities/$ENTITY_ID/accounts/$ACCOUNT_ID/sends" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "preview_token": "<token>",
    "idempotency_key": "partner-send-001"
  }' | jq '.data'
```

Confirm requires a funded USDC balance (see [Fund an account](/deposit-accounts/accounts#fund-an-account)). As with book-transfers, re-confirming the same `idempotency_key` returns the prior send. Poll `GET .../sends/{send_id}` or wait for `account.send.completed` / `account.send.failed`.
